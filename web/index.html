Survival estimates

Enter all numeric values or load the synthetic example, then select Calculate survival.

Outputs use the original exponential baseline hazard of 0.0405/year. The 5-year value is an extrapolation of the 2006 equation, not the recalibrated SHFM estimate.

Reference: Levy WC et al. The Seattle Heart Failure Model: prediction of survival in heart failure. Circulation. 2006;113:1424–1433. DOI 10.1161/CIRCULATIONAHA.105.584102.

The model is derived principally from systolic heart failure cohorts; calculated associations are not causal treatment effects. No values are transmitted, stored, or downloaded by this page. Source code.
